# fixtures/

Тестовый стенд: локальный торрент из открытой короткометражки.

## Зачем не реальный трекер

Из цепочки «bridge добавил → *arr нашёл релиз → торрент скачался → файл
переехал жёсткой ссылкой с каноничным именем» трекеры участвуют в одном
звене — и это самое **недетерминированное** звено: есть ли раздача сегодня,
сколько сидов, какая скорость. Агент в отладочном цикле будет получать
красное от того, что раздачу не нашли, и лечить код.

Плюс приватные трекеры банят за поток запросов, а рейтинг и бан необратимы.

Локальный торрент: данные уже на месте, поэтому 100 % сразу, сеть не нужна,
результат воспроизводим, `searchForMovie: false` в dev-режиме остаётся
неотключённым.

Реальные трекеры подключает человек, вручную, один раз, когда конвейер
уже зелёный.

## Требования к материалу

1. **Существует в TMDB** — иначе Radarr не сопоставит
2. **Открытая лицензия**
3. **Настоящий видеофайл.** У него есть длительность, кодек, разрешение,
   поэтому MediaInfo и определение качества у *arr работают честно.
   Файл-пустышка может быть отброшен как sample, и тогда проверка ничего
   не проверит

Кандидаты: открытые ленты Blender (Big Buck Bunny, Sintel, Tears of Steel,
Cosmos Laundromat) под CC-BY; из общественного достояния — Steamboat Willie.

## Что заполнить перед первым запуском

В `catalog.yml`:

- **`url`** — прямая ссылка на видеофайл. Ссылки на зеркала открытых лент
  меняются, поэтому проверить руками
- **`series[].tmdb_id`** — любой реальный сериал, у которого в TMDB
  `external_ids` **есть** `tvdb_id`

`tmdb_id` фильмов заполнять не нужно: `make-fixture.sh` разрешает его через
TMDB API по названию и году. Хардкодить идентификатор по памяти — прямой путь
к тому, что тест проверит не тот фильм.

## Сериалы

Сериалов с открытой лицензией и записью в TVDB практически нет. Обход: взять
`tvdb_id` реального сериала, а файлом положить ту же короткометражку,
переименованную в `SxxEyy`. Sonarr сопоставляет по имени, не по содержимому,
поэтому импорт проверяется честно.

Держать **только** в выбрасываемом `TEST_SONARR_ROOT`, чтобы потом не
разбирать это в настоящей библиотеке.

## Что не коммитится

`data/` и `*.torrent` — в `.gitignore`. Репозиторий остаётся лёгким,
стенд воссоздаётся `make-fixture.sh`.

## Зависимости

`curl`, `jq`, `yq`, и `mktorrent` либо `transmission-create`.
