# reports/

Отчёты по этапам. **Коммитятся вместе с кодом** — иначе находки агента
испаряются вместе с сессией.

Имя файла: `stage-<N>-<краткое-имя>.md`

Форма — в `docs/PROCESS.md`, раздел 5. Обязательное требование:
**точные запросы и ответы, а не пересказ.** «Не получилось добавить сезон»
бесполезно; тело запроса и тело ответа — достаточно, чтобы понять причину
без повторения эксперимента.

Каждый отчёт ссылается на пункт `docs/OPEN-QUESTIONS.md`, который он затронул.
Подтверждённое переносится в `docs/SPEC.md`, пункт удаляется; опровергнутое
переписывается с фактами.
